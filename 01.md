# Personal Health Insight Tracker — Project Documentation

This document provides a comprehensive overview of the **Personal Health Insight Tracker** mobile application, including its architecture, core modules, and implementation details.

---

## 1. Project Overview
A medical-adjacent personal health tracker designed for migraine sufferers, IBS patients, and sleep-conscious professionals.

- **Goal**: Log symptoms, track lifestyle factors, detect patterns, provide actionable insights, and generate doctor-ready reports.
- **Platform**: Flutter (Android & iOS).
- **Backend**: Firebase (Auth, Firestore, Messaging).
- **AI Engine**: Statistical correlation (Pearson) + AI LLM (OpenAI/Gemini) for plain-language insights.

---

## 2. Core Architecture & Folder Structure

The project follows a modular architecture using **Riverpod** for state management and a service-oriented data layer.

```text
lib/
├── main.dart             # App Entry point (Initialization)
├── app.dart              # Root Widget & Shell (Navigation)
├── models/               # Data Entities (SymptomLog, LifestyleEntry, UserModel, Correlation)
├── services/             # Logic & Infrastructure (Auth, Database, AI, PDF, Notifications)
├── providers/            # Riverpod State Providers (Bridging UI and Services)
├── screens/              # Primary UI Modules (Home, Logging, Insights, Reports, Settings)
├── widgets/              # Reusable UI components (Sliders, Charts, Cards)
├── charts/               # Visualization components (fl_chart)
└── utils/                # Helpers (Theme, Validators, Math, Constants)
```

## 3. Implementation Modules

### Module 1: Foundation & Data Layer
- **Firebase Integration**: Authentication and Firestore storage.
- **Offline-First**: Uses `LocalCacheService` (Hive) to ensure logging works without an internet connection.
- **Models**: Clean, serializable models for all health data.

### Module 2: High-Speed Logging
- **UX Goal**: Under 30 seconds to log a complete daily entry.
- **Features**: Quick-select symptom chips, severity sliders (1-10), and lifestyle tracking (sleep, stress, hydration, exercise).
- **Logic**: Input validation via `AppValidators` and automated nudge triggers.

### Module 3: Pattern Detection & AI Insights
- **Statistical Engine**: Calculates the relationship between lifestyle (triggers) and symptoms using math-based correlation.
- **AI Engine**: Premium feature using LLMs to generate human-readable summaries: *"Your migraines are 80% correlated with poor sleep (<6hrs) over the last 30 days."*
- **Visuals**: Timeline charts and correlation bar charts using `fl_chart`.

### Module 4: Doctor-Ready Reports
- **PDF Export**: Generates professional PDF reports using the `pdf` and `printing` packages.
- **Content**: Includes an executive summary, top triggers list, and a detailed table of recent logs.
- **Sharing**: Native platform share sheets for email, printing, or messaging.

### Module 5: Engagement & Nudges
- **Daily Reminders**: Local notifications scheduled to encourage consistent logging.
- **Smart Nudges**: Immediate feedback based on logs (e.g., "You're dehydrated, drink water to avoid a headache").
- **Gamification**: Tracking "Wellness Scores" and "Logging Streaks" to drive long-term habit formation.

## 5. Production Readiness
- **State Management**: Providers isolate business logic from UI.
- **Security**: User data is isolated by UID in Firestore; sensitive keys handled via environment variables.
- **Accessibility**: High-contrast theme, large touch targets, and screen-reader labels.
- **Monetization**: Freemium model with feature-gating for AI insights and advanced PDF reports.
